# Sistema de Ventas — Mueblería de Melamina

Sistema web para gestionar inventarios, ventas en stock y pedidos de muebles a medida con anticipos y notas de fabricación para taller. Desarrollado como proyecto de producción real.

## Tecnologías

- HTML5, CSS3, JavaScript (ES6+)
- Supabase (PostgreSQL, Authentication)

## Estructura del proyecto

- `docs/`: Documentación del proyecto (requerimientos, historias de usuario, casos de uso, modelo de datos, diseño de interfaz).
- `diagramas/`: Diagramas ER de base de datos y wireframes de interfaz.
- `pages/`: Pantallas secundarias del sistema (productos, clientes, ventas).
- `css/`: Estilos visuales del sistema.
- `js/`: Lógica de interacción, cálculos y conexión con Supabase.
- `assets/`: Imágenes, logos e íconos del sistema.
